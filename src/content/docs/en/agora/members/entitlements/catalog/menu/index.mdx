This guide explains how to manage the food and drinks your business offers in Agora. It is for members with merchant administration access.

## Where to manage your menu

Open your merchant workspace in [Agora](https://agora.myglobal.site) and go to **Catalog → Menu**. Merchant Admin V2.5 is the current version. If you reach an older screen, treat it as the legacy V1 interface and return to the current merchant workspace.

Menu must be enabled for the merchant. If Agora cannot verify access or says Menu is unavailable, you can review existing data but cannot save changes. Ask the merchant owner to check the **Menu** capability; a Pro membership by itself does not guarantee this capability is enabled.

## Organize the menu into groups

Groups organize menu items, such as “Breakfast” or “Drinks.” They are not offer types or permissions.

1. Under **Menu → Items**, choose **New group**.
2. Enter a name. You can add a description, set the display order, and choose an image.
3. Save the group. Select it to view its items.
4. To change it, use **Edit group** next to its name.

Create at least one group first: each item must belong to a group.

## Add or edit an item

1. Select the group for the item and choose **Add item**.
2. Enter the name and group. Add a short summary, description, and price to make the offer clear.
3. Optionally, choose an image. The screen shows a preview; the image uploads when you save the item.
4. Under menu details, you can add dietary or allergen tags and allow a half-and-half combination when appropriate.
5. Choose a status and save. To change an item, choose **Edit** on its row.

Use **Archive** to remove an item from the active catalog. Check the status and customer catalog preview before sharing the page with customers.

## Set up modifiers

Modifiers let customers choose options for an item, such as size, ingredients, or extras.

1. Open the **Modifiers** tab.
2. Create an options group, set how many options a customer can choose, and whether a selection is required.
3. Add the options, their price adjustments, and their order. You can mark an option active or inactive.
4. Link the group to the menu items that use it.

Check the options in the preview to confirm that selections and prices appear as expected.

## Review the customer view

Choose **Preview customer catalog** to review how the catalog appears. Use the preview to catch names, images, prices, groups, or availability that need changes.

:::tip[Start with the essentials]
Add clear groups, publish only available items, and review the catalog from the customer's perspective before sharing it.
:::
