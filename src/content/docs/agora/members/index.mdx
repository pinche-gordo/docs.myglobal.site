Los miembros pueden usar las herramientas de Agora que estén habilitadas para su negocio y su acceso. La membresía de MYGLOBAL.site y las capacidades comerciales de Agora son distintas: tener Pro no significa que todas las funciones de Agora estén habilitadas.


Para ver las funciones disponibles para cada negocio, consulta [beneficios y herramientas para miembros](/agora/members/entitlements/).

Las guías detalladas para tareas de miembros se añadirán conforme verifiquemos cada flujo.
