Esta guía explica cómo organizar productos y describir cómo se entregan. Está dirigida a miembros con acceso de administración al comercio.

## Dónde administrar productos

Abre el espacio de administración de tu comercio en [Agora](https://agora.myglobal.site) y entra en **Catálogo → Productos**. Merchant Admin V2.5 es la versión actual. Si llegas a una pantalla anterior, considérala la versión heredada (V1) y vuelve al espacio actual del comercio.

Productos debe estar habilitado para el comercio. Si Agora no puede verificar el acceso o indica que no está habilitado, podrás revisar los datos existentes, pero no guardar cambios. Pide al propietario del comercio que revise esta capacidad; una membresía Pro por sí sola no garantiza que esté habilitada.

## Organiza los productos

Los grupos ayudan a ordenar productos relacionados, por ejemplo, “Accesorios” o “Cuidado personal”. Son una forma de organización del catálogo, no permisos ni tipos de oferta.

1. En **Productos**, elige **Nuevo grupo**.
2. Escribe un nombre. Puedes añadir una descripción, ordenar el grupo y elegir una imagen.
3. Guarda el grupo; después selecciónalo para revisar sus productos.

## Agrega o edita un producto

1. Selecciona el grupo y elige **Agregar elemento**.
2. Completa el nombre, resumen breve, descripción y precio.
3. Agrega al menos una imagen válida del producto. Puedes previsualizarla antes de guardarla.
4. Elige el tipo de inventario:
   - **Existencias ilimitadas** si no vas a registrar una cantidad disponible;
   - **Controlar existencias** si necesitas indicar la cantidad disponible;
   - **Preventa** si el producto se ofrece antes de estar disponible.
5. Elige cómo se entrega:
   - **Producto físico**;
   - **Entrega digital**, con enlace de descarga o entrega de clave;
   - **Entrega externa**, con el enlace indicado para cumplir la oferta.
6. Añade etiquetas si ayudan a describir el producto, elige su estado y guarda.

Para cambiar un producto, usa **Editar** en su fila. Si controlas existencias, indica la cantidad antes de guardar. La pantalla requiere al menos una imagen válida para guardar el producto.

## Revisa el catálogo

Elige **Previsualizar catálogo de clientes** para comprobar cómo se muestran el producto, sus imágenes, precio y estado. La configuración de entrega describe la oferta; no confirma por sí sola que un proceso de descarga, envío o entrega externa esté operativo.

:::tip[Antes de compartir]
Confirma que la imagen corresponde al producto, el precio está actualizado y la forma de entrega está explicada con claridad.
:::
