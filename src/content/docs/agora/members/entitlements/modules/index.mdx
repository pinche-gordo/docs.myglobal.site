description: Módulos comerciales de Agora que se habilitan por separado.

Los módulos habilitan áreas de trabajo para un negocio. No son tipos de oferta del catálogo.

- [**Reservas (Booking)**](/agora/members/entitlements/modules/booking/): módulo independiente para flujos de reservas; es distinto de las citas nativas de MYGLOBAL.site.
- [**Bienes raíces (Real Estate)**](/agora/members/entitlements/modules/real-estate/): módulo independiente para operaciones inmobiliarias y listados.

La disponibilidad depende de los beneficios habilitados y de la configuración del negocio. Las guías detalladas se publicarán tras verificar cada flujo.
