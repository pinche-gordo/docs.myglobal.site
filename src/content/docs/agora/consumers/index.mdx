Puedes explorar los catálogos públicos de Agora sin incorporarte como miembro de MYGLOBAL.site. Algunas acciones pueden pedirte iniciar sesión como consumidor; sigue las indicaciones que muestra Agora. El acceso de consumidor y la membresía de MYGLOBAL.site son flujos distintos.

[Explorar Agora](https://agora.myglobal.site/explore)

Las guías detalladas para tareas de consumidores se añadirán conforme verifiquemos cada flujo.
